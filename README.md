# NicTvChannel Plus

Aplicación Android para reproducir listas de canales mediante streaming HLS con Media3 ExoPlayer. El proyecto fue creado como ejercicio de desarrollo móvil y configuración de reproducción multimedia.

## Tecnologías

- Java, Android Studio y AndroidX
- Media3 ExoPlayer y HLS
- Firebase Remote Config (configuración opcional)

## Configuración

Abre el proyecto en Android Studio. Si habilitas Firebase, agrega tu propia configuración de Firebase en `app/google-services.json` (archivo local que no se incluye en este repositorio). Configura una lista M3U para contenido que tengas autorización de distribuir o reproducir.

El enlace de demostración es ficticio y debe sustituirse por una fuente autorizada. No se incluyen listas de canales ni enlaces de terceros.
